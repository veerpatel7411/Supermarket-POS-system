# Supermarket-POS-system
MarketBridge POS is an Electron supermarket POS using an embedded central SQLite database and local TLS API over Wi-Fi/Ethernet.  Quick Setup:  Install Node.js ≥22.12.  Run npm install, npm test, then npm run build:win.  Find the NSIS installer in deliverables/.  Launch server host first, then pair tills via PIN. Demo:
